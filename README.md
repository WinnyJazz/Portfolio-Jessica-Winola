# Jessica Winola's Portfolio

Hello everyone! 👋 This is my personal portfolio project, built to showcase who I am, my skills, and my journey so far as a Computer Science student.

I learned the foundations for this project in my Front-End Development class during my 3rd semester, and I continued developing it further from there — adding my own sections, styling, and features along the way.

🔗 **Live site:** https://portfolio-jessica-winola-omega.vercel.app

## About This Project

This portfolio includes:
- **Home** — a short introduction about me
- **Tech Stack** — the languages, frameworks, databases, and tools I work with
- **Experience** — my organization and work experience
- **Contact** — ways to reach me (LinkedIn, WhatsApp, Email, Instagram)

## Built With

- [Next.js](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)

## Running Locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This project is deployed on [Vercel](https://vercel.com/).
